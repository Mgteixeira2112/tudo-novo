# Ajuste visual do Motor de Reservas

Correção de layout após homologação da FASE 3.1.

- hero mais compacto no desktop;
- barra de datas mais próxima das acomodações;
- cards de acomodação mais baixos;
- grid de até 3 colunas em telas largas;
- rodapé de preço e ação reorganizado;
- botão `Reservar Agora` com alinhamento e largura segura;
- estrutura mobile preservada.

Nenhuma regra de reserva, Supabase, RPC ou proteção contra overbooking foi alterada.
